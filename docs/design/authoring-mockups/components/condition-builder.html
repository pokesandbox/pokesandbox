Phone · a row that points at a deleted location

  • Shape: the Rule-group editor set up for conditions: an "All of" or "Any of" list, groups one level deep with their own All of / Any of, and "Not" on any row. Deeper trees come by JSON import later.
  • Templates first: each chip adds a ready-made row (Badge… adds "Has badge" and opens the badge picker). Most authors never pick a raw fact. "Add condition" opens the full fact list (badge, progression, item, party move or species, visited, flag, time of day, money).
  • Rows are fact · operator · value, with the value input matching the fact: badge, item, move and location comboboxes, a number, a segmented control for time of day or "is set / not set yet". Only once needs no value.
  • Reads as updates live from the same explainer players see when something is locked. Rows with problems still save (so work isn't lost), but they show here and in Region Health, and block publish.
  • Phones: a tall bottom sheet over the page, with Save pinned. Desktop: a 480px side panel, so the thing being gated stays visible.
