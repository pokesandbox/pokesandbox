Notes

  • Every field autosaves on blur; the app bar shows Saving… then Saved. No Save button.
  • New game is the script that runs when a player starts this region. The row shows its step count and opens it in the step editor. Kanto Classic starts with Oak’s welcome, naming the rival, and the move to Your House 2F.
  • Starting location is where a player lands if the New game script has no Move step (or there's no script).
  • Starting and respawn locations use the location SearchCombobox (full-screen picker on phones). The respawn help explains when it applies.
  • The symbol has a live sample ("₽500") so authors see how prices read.
  • The rules preset is an editable select. Only Classic Gen 1 exists for now; other presets show as "coming later". Changing rules later is allowed, and the change is checked when you publish (doc 18). The TMs & HMs rule (single use or reusable) is shown under it, because the TM screen points here.
  • Name and description live here too, so Settings is the one place for region-wide fields.
