Notes

  • Explore, not Encounters (doc 10). The tab covers everything pressing Explore can find here: wild Pokémon by method, trainers on Explore, and hidden items.
  • Players choose the method. Each method is its own button in Discord ("Walk in the grass", "Fish (Old Rod)", "Surf"), shown only when this location has a table for it and its requirement passes.
  • The rate is the share of presses that give a wild Pokémon. The rest find this location's trainers and items while any are left; with none left, every press is wild. It defaults to the region's value for the method ("Region default · 70%"), and Override sets this location's own.
  • Surf and the rods are wild only, so 100% is normal: "Fishing only finds Pokémon".
  • No default method. A new location has no Explore until you add one. Routes and dungeons suggest a starting point ("Add grass encounters", "Add cave encounters"); other kinds get a plain "+ Method".
  • Below the methods, read-only counts of the other outcomes (trainers on Explore, hidden items) and the traversal cost, each linking to where it's edited.
  • Slots: species, min and max level, weight; % is weight ÷ total, live. Validation sits on the row ("Min level is above max."). Conditional tables (night, swarms) use the condition builder (K3).
