Connections tab · gated exit

  • Doc 10 § Traversal requirements is the source: Location.traversal { exits: 'all' | keys, firstPass { trainers, trainerBattles, wildBattles, explores }, everyPass { explores } }. The builder compiles it into attemptable gates on the chosen exits.
  • Off by default ("Players can pass through freely"). Turning it on opens the sections below; turning it off keeps the values in case it comes back on.
  • Which exits: all, or a checklist of this location's connections (direction matters: north to Pewter City, not south to Route 2).
  • First time through is one-time: specific trainers (picked from this location's trainers) and optional counts. Every time through is a minimum number of explores, for caves and forests. The first pass needs both.
  • Preview shows the locked message on the gated exit, built from the settings ("Defeat Bug Catcher Rick and 1 more trainer to continue", "Keep exploring: 2 more steps to get through"). Change a number to see it update. Repel still counts toward explores: a step that would have found a weak Pokémon becomes a safe step.
  • On the Connections tab a gated exit shows a "Traversal cost" badge that links back here. Its own requirement (K1) still works alongside it.
  • Desktop: the same sections in the Explore tab's detail pane.
