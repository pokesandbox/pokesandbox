  • Per exit, shared when you want: a location has any number of costs; each cost applies to one or more exits ("Applies to", with an All exits shortcut), and editing it updates every exit it covers. An exit belongs to at most one cost; exits with none are free. Proposal: doc 10 has one Location.traversal with an exits list; this needs traversal.costs[{ exits, firstPass, everyPass }].
  • First visit and later visits stack; nothing switches between them. On a player's first time through they need both; after that, only Every visit applies. The sheet says so above the two sections, and the preview shows each case.
  • Every visit counts explores (doc 10). Proposals: wild encounters, where Repel-avoided ones count too, so Repel still speeds you through but you fight the rest if it runs out; and trainer battles for punishing regions, which warn unless a trainer here battles again every visit (rematches are post-MVP, doc 11). Without one, the exit could never open.
  • Preview builds the locked message for the chosen exit and visit ("Defeat Bug Catcher Rick and 1 more trainer to continue", "Keep exploring: 2 more steps to get through").
