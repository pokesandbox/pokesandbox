Notes

  • Two kinds of cost, each its own card: First time through (paid once per exit, the first time a player uses it) and Every time through (paid on each visit). Each card applies to one or more exits, with an All exits shortcut. An exit has at most one of each kind, and can have none.
  • Requirements work like conditions: a list that needs All or Any of its rows, plus one group with its own All or Any. Any requirement can be moved into or out of the group, the group has Add to group, and + Group adds one when there isn't one. Removing the group moves its rows back out. "Reads as" spells out the result. All of this works in the sheets here.
  • Same editor as conditions: this is the rule-group editor the condition builder uses, configured with traversal requirements instead of facts, without Not, and with each requirement allowed once.
  • First time can ask for: trainers who must be beaten, wild battles won, explores. Every time can ask for: explores, wild encounters (ones a Repel avoids count too).
  • Split one exit off: an exit's menu has "Edit just this exit", which makes a new cost for that exit with the same requirements and opens it. Ticking an exit that has another cost of the same kind moves it there.
  • Preview builds the locked message for an exit and a visit.
