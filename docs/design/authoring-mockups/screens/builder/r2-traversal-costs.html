Connections tab · each exit's cost

  • Per exit, shared when you want: a location has any number of costs; each applies to one or more exits ("Applies to", with an All exits shortcut), and editing it updates every exit it covers. An exit belongs to at most one cost; exits with none are free. Proposal for doc 10: traversal.costs[{ exits, firstPass, everyPass, detachedFrom? }] replaces the single traversal.
  • All or any: each section has "Needs: All of these / Any one". All means every requirement in the section must be met; Any one means the first one met is enough (e.g. 3 explores or 2 wild encounters). Required trainers count as one requirement.
  • Detach one exit: an exit's menu in a shared card has "Edit just this exit". It copies the shared cost into a new card for that exit only, marked "Detached from Forest walk", and opens it; the shared card no longer covers that exit.
  • Re-include: checking a detached exit in its old shared card's Applies to confirms first, then deletes the detached card. Adding an exit that belongs to another regular cost just moves it.
  • First visit and later visits stack: on the first time through both sections apply; later, only Every visit. The preview shows each case.
  • Every visit counts explores (doc 10). Proposals: wild encounters (Repel-avoided ones count too), and trainer battles, which warn unless a trainer here battles again every visit (rematches are post-MVP, doc 11).
