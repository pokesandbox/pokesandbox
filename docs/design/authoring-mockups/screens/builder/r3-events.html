Notes

  • When a player… lists what happens at this location: the event, Automatic or the button label, Once, the condition, and the script it runs.
  • Events are picked from a dropdown: enters this location (optionally only from chosen places or by a way of travel), leaves this location (optionally only toward chosen exits), explores here, uses an item here, uses a move here.
  • Leaving runs after the exit's requirement passes and before the player moves, so its script can stop them: a riddle they get wrong, an urgent story beat. If it does, they stay here and the next location isn't marked visited.
  • Uses a move here covers field moves at this location (Headbutt trees, Strength boulders, Rock Smash rocks). Obstacles that only block a path stay requirements on the connection.
  • Runs: Automatically (as soon as the event happens) or As a button (players see the label, e.g. "Talk to the old man").
  • Only once means it never runs again for that player, so it doesn't need a condition for that.
  • Priority stays hidden until two events can happen at the same moment; then the sheet shows it with a warning naming the other one.
  • Script: pick one, or Create from template. A template-made script opens its form; others open read-only for now.
  • From an NPC: the Talk script row on an NPC opens this same sheet, with the event fixed to talking to them.
