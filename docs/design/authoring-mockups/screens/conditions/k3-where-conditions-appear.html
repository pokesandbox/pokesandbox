3 · Details: description variants

  • Same row everywhere: each attach point shows the K1 summary and opens the K2 editor. Only the empty text changes ("Anyone can travel here", "Always used", "Shown when…").
  • Gate settings stay on the attach point. A connection adds "When it isn't met" (Hide · Show locked · Let them try, defaulting to Hide for connections), optional locked text that replaces the generated explanation, and "Once passed, always passed" (the latch). These belong to the gate, not the condition.
  • Ordered alternatives (encounter tables, description variants) are numbered cards; the first whose condition matches wins, and the last entry is the unconditioned default, which can't be moved or given a condition. Reorder with the handle or Move up/down.
