Notes

  • Where: a "Player view" tab on the builder's Pokédex screen (next to Slots). It's region content, so it's part of the release and takes effect when published.
  • Presets first: Open book (everything always), Like the games (default: seeing shows the basics, catching shows the rest) and Spoiler-safe (almost everything needs a catch, and unseen entries hide their names). Changing a field switches the preset to Custom.
  • Per field: each kind of dex info is Always, After seen, or After caught. "Where to find it" has its own row because it's the biggest spoiler.
  • Visitors (people not playing the region) see either everything or the same as a brand-new player.
  • Preview as a player opens the region Pokédex as a player with nothing, something seen, or something caught.
  • Data: seen and caught would be journey state (the journey holds all engine state, doc 23); this setting only decides what the pages reveal. It never changes gameplay.
