New progression (sheet)

  • Matches today's Discord builder and the shared model: three kinds, set when created. Milestones (an ordered list, optionally sequential; badges are milestones with an image), Numeric (a number with optional min and max), and Flag (on or off, boolean in the model). Every progression has a name, description and visibility.
  • Visibility (Public / Discoverable / Hidden) has a one-line explanation under the control. The wording here is a proposal; the bot doesn't describe these yet.
  • Milestones are a sortable list: image placeholder, name, description. Order is the position number from Discord. Sequential means they must be earned in that order.
  • Used by lists every condition, reward and template that references this progression, each linking to it, so deleting or renaming is safe. Delete is blocked while anything uses it.
  • Choice (for example "starter chosen", used by the rival's party variants) isn't a kind in the model yet; it's shown greyed in New progression as an open question.
