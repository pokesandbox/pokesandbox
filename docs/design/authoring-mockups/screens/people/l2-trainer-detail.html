Notes

  • Name placeholders: the hint chip inserts {name:rival}, which becomes the name the player gave their rival.
  • Payout: Formula is the default and shows its result for the current party; Fixed swaps in a number field.
  • Party variants are ordered cards, each with a condition (K1). First match wins. Collapse the ones you're not editing. Add, Duplicate, reorder by handle or More → Move up/down.
  • The bag is per variant, following doc 11 (parties[].items), so a later team can carry better items.
  • Warning: no variant is unconditioned, so if none match the battle can't start. Region Health shows the same.
  • Moves: empty slots show what the engine will pick ("Auto: Scratch", the last four level-up moves). Override sets a move; Reset returns to auto.
  • Held item is shown but off: Classic Gen 1 rules have no held items. Rules presets with them turn it on.
  • Lines: intro and defeat are passages with a Discord preview that fills placeholders with a sample name. Post-battle talk is the NPC's job.
