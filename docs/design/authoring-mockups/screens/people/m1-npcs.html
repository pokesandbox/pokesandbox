Non-battle NPC · Nurse Joy

  • An NPC is who stands there; a Trainer is how they battle. Linking a trainer is optional, and the Engagement section only appears once one is linked.
  • Presence: Single uses the first placement whose condition matches (story characters who move). Everywhere uses every matching placement (Nurse Joy in every Center). The explanation under the control changes with the choice.
  • Placements are ordered, each with a location, a condition (K1), and an optional talk-script override for that spot. With Single presence, two placements that can both match get the warning "Two single placements can match at the same time; the first wins."
  • Talk script: link an existing script, or "Create from template" (Group 3). The raw step editor comes later.
  • After defeat (doc 11): stay or leave, plus the after-battle talk script. This is where the trainer's "post-battle talk lives on the NPC" note points.
  • NPCs who don’t battle (Nurse Joy, Mom, clerks, item givers) leave Trainer empty. Engagement and After defeat are hidden; what’s left is name, sprite, presence, placements and talk script. Linking a trainer later brings those sections back.
  • No tabs: an NPC fits one scrolling form, with section headings.
