Notes

  • No seen or caught here: the canon page has no journey. Per-form seen and caught appear on a region's Pokédex entries.
  • Canon only, no context: /species/meowth shows the species as the catalog has it, not tied to a server, region or journey. Nothing is gated; there's nothing to spoil.
  • Rules selector: defaults to the latest rules. Switching to a preset (Classic Gen 1) redraws the same sections the way that preset sees them: one Special stat, no abilities or gender, Gen 1 learnset. The choice is in the URL (?rules=classic-gen1).
  • Same sections as the builder panel (stats, details, evolution, forms, moves), in a page shell: public header, breadcrumb, shareable URL. No TM list here: TM compatibility depends on a region's TM case, so it lives on region pages.
  • Regions that feature Meowth lists public regions whose published Pokédex includes it, each linking to that region's entry.
  • Custom species use the same page at /publishers/:publisherId/species/:slug, with a publisher credit band under the header and "Regions using this species". Only species a publisher made public are listed or searchable.
  • Search (header) finds canon and public custom species by name or number.
