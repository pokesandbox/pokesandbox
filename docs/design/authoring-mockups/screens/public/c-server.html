Notes

  • Visitors see only published regions: name, the version players are on, and the player count. A row opens the public region page.
  • Admins and mods also see an admin strip with "Create region", and every region, unpublished drafts included.
  • Each admin row shows its status (Draft with unpublished changes, or Published) and its own "Open builder".
  • A region that has never been published shows only "Not published" and no player count.
  • From md up the rows become a two-column grid; the layout doesn't otherwise change, so no desktop frame.
