Notes

  • Scripts is its own section in the builder: every script in the region with its step count and what uses it, searchable and filterable (used by NPCs or events, made with a template, not used, has issues). "+ Script" starts an empty one. Scripts also open from wherever they're used.
  • A script is a list of steps that run in order. This editor has no choices, branches, labels or gotos; those come with the full editor.
  • Header: the script's name and key, the saved / saving indicator, and Used by: the events and Talk rows that run it, each opening where it's set.
  • Each step is an icon and a one-line summary. Tap it to edit in a sheet. Reorder by the drag handle, or with Move up / Move down in the ⋯ menu, which also has Duplicate and Delete.
  • Add step picks one of eight types: Text and Ask for a name; Give and Take; Set a flag, progression or badge; Battle a trainer and Heal; Move the player.
  • Text holds one or more passages, each shown with Next (+ Passage adds another). It's the passage editor, with {name:player} and {name:rival} inserts and a Discord preview that fills in sample names.
  • Take: if they don't have it, the script stops there. That's fixed, so the step says so instead of offering a choice.
  • Set creates a flag inline when the name doesn't exist yet. A progression takes a value; a badge is just picked.
  • Validation sits on the row: a warning when a Take step's item isn't checked for by anything that runs the script, and an error when a step points at a deleted trainer or location. Both also appear in Region Health.
  • Read-only: a script made with a template opens its form instead ("Edit as form"); a script with choices or branches shows its steps but can't be edited until the full editor arrives.
  • New script: one step to start, "Add the first step".
