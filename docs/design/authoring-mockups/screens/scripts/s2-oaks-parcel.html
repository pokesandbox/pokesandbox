How it plays

  1. Viridian Mart: the first time a player walks in, the clerk hands over Oak's Parcel. The event runs automatically, once, and only before oak_parcel_delivered.
  2. Viridian City's north exit: the connection to Route 2 requires oak_parcel_delivered. Players still see "North" and can press it; until the parcel is delivered they're turned back with the guard's line.
  3. The guard only talks. His Talk script has the same condition, so once the parcel is delivered he has nothing more to say. A Talk script can't stop anyone; the gate does.
  4. Oak's Lab: talking to Oak runs the first Talk script whose condition matches. With the parcel in the bag, he takes it, gives the Pokédex and sets the flag; otherwise he says his usual lines.
  5. No branches needed: each "Oak, once you have the parcel" moment is its own Talk script, event or gate with a condition, so every script here is a straight list of steps.

Talk section

  • "Talks differently when…" lists an NPC's Talk scripts in order; the first whose condition matches runs. Reorder by handle or the ⋯ menu.
  • The last one usually has no condition and reads "Otherwise". With a single Talk script it reads "Always".
  • If none match, players don't see a Talk button for that NPC.
  • Each row opens the event sheet with the event fixed to talking to them; its script opens in the step editor, or in its form if a template made it.
