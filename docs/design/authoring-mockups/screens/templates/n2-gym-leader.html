Notes

  • Six short steps on phones, each with Continue pinned above the keyboard. Back keeps what you typed. Steps you've finished can be jumped to from Review.
  • The location picker only offers Gym locations. The party step is the L2 party editor with a single team (no variants); variants can be added later on the NPC.
  • Milestone awarded is a progression plus one of its milestones, so a region with trials instead of badges uses the same template (pick "Trials" and "Ocean Trial").
  • No badges yet: step 3 says so and offers Create Badges (a quick-create sheet: name, kind, first badge, all prefilled), Use another progression, or No milestone. You never leave the form. Full editing is on the Progressions screen, which lists it as used by this leader.
  • Intro, defeat and after-defeat text are passages with the Discord preview.
  • "Require gym trainers first" is off by default (doc 11). On, it adds a gate to the leader: hidden, shown locked, or "Not so fast!".
  • Items given is a list of any items with quantities. TMs are items here, found by number or move name, so a leader can give a TM, a Bike Voucher, both, or nothing.
  • Review lists exactly what will be created. Create opens the new NPC with a banner: it came from a template, the script can be re-opened in the template form, and the step editor comes later.
