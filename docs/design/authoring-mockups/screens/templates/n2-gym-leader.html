Notes

  • Six short steps on phones, each with Continue pinned above the keyboard. Back keeps what you typed. Steps you've finished can be jumped to from Review.
  • The location picker only offers Gym locations. The party step is the L2 party editor with a single team (no variants); variants can be added later on the NPC.
  • Badge awarded picks a badge, which is a milestone in the region’s Badges progression. The template stays gym-focused; regions with trials get a Trial Captain template later.
  • No badges yet: step 3 says so and offers Create Badges (a quick-create sheet: name, kind, first badge, all prefilled) or No badge. You never leave the form. Full editing is on the Progressions screen, which lists it as used by this leader.
  • Intro, defeat and after-defeat text are passages with the Discord preview.
  • "Require gym trainers first" is off by default (doc 11). On, it adds a gate to the leader: hidden, shown locked, or "Not so fast!".
  • Items given is a list of any items with quantities. TMs are items here, found by number or move name, so a leader can give a TM, a Bike Voucher, both, or nothing.
  • Review lists exactly what will be created. Create opens the new NPC.
  • Templates stay linked until a hand edit (doc 07). The NPC and its script show "Made with the Gym Leader template" with Edit as form, which reopens the filled-in form; saving regenerates the script in place, keeping its key and the NPC and trainer it made.
  • Edit steps (the step editor, which comes later) confirms first: "This script will no longer be editable as a Gym Leader form." After that the link is gone.
